# Specification: Comprehensive $10k-Tier Portfolio Elevation

## 1. Architectural Objective
Elevate the entire portfolio from a template look to an international award-winning (Awwwards / Studio Freight / Locomotive) caliber digital showcase for "DC", Creative Technologist & Systems Architect:
- Unified obsidian void atmosphere (`#030508`).
- 3D interactive WebGL liquid glass core in the Hero (replacing the 2D pixel-art avatar).
- Architectural display typography with tight negative letter-spacing and Space Mono telemetry.
- Awwwards-grade "Selected Works" showcase with 3D refractive glass cards (`liquid-glass-js`).
- Structured Engineering Radar (Creative Computing, Full-Stack Systems, Tooling & Performance).
- Minimalist architectural Experience & Open Source milestones.
- Strictly zero emojis, clean tactile micro-animations.

## 2. Component Blueprint

### 1. Global Tokens & Atmosphere (`src/styles/globals.css`)
- Foundation background `#030508`.
- Deep obsidian backdrop with 1px architectural hairline grid borders (`rgba(255, 255, 255, 0.08)`).
- Replace noisy gradient blobs with subtle ambient cold-cyan and cobalt specular vignettes.
- Space Grotesk / Inter headings + Space Mono telemetry tokens.

### 2. Interactive 3D Liquid Glass Core (`src/components/ThreeCanvas/LiquidGlassCore.jsx`)
- Replaces 2D avatar and separate wireframe with a unified interactive 3D WebGL liquid glass artifact:
  - Custom shader with Simplex noise vertex deformation reacting to pointer coordinates.
  - Chromatic dispersion and specular highlights.
  - Orbit parallax and floating orbital particle dust.

### 3. Hero Section (`src/components/Hero/Hero.jsx` & `Hero.module.css`)
- Clean architectural badge: `[ CREATIVE TECHNOLOGIST // PRODUCT ARCHITECT ]`.
- Confident display title: "Engineering digital experiences at the intersection of design, code & real-time 3D."
- Micro-telemetry: `AVAILABLE FOR SELECT PROJECTS // 2026` · `NYC / REMOTE`.
- Magnetic liquid glass action buttons: `[ EXPLORE SELECTED WORKS ]` and `[ GITHUB REPOSITORIES ]`.
- Architectural metrics bar: `12+ OSS PACKAGES`, `1.2K+ COMMITS`, `890+ GITHUB STARS`, `99.9% RELIABILITY`.

### 4. Selected Works (`src/components/Projects/Projects.jsx` & `Projects.module.css`)
- Awwwards-style case study presentation with full-bleed cards and 3D gyroscope tilt.
- Numbered index (`01`, `02`, `03`...), domain tags (`REAL-TIME 3D // 2026`), live preview viewport, monospace tech chips, and direct launch links.

### 5. Skills & Tech Radar (`src/components/Skills/Skills.jsx` & `Skills.module.css`)
- Domain-driven architectural grid:
  - `01 / CREATIVE COMPUTING & SHADERS`

### 6. Experience & Trajectory (`src/components/Experience/Experience.jsx` & `Experience.module.css`)
- Sleek architectural timeline entries with quantified production impact.
